# FuiCs.Runtime

The EffinDOM browser runtime for FuiCs applications: the bridge script, the
runtime manifest, the core and UI WebAssembly modules and the bundled fonts,
from the `@effindomv2/runtime` npm package of the same version. The `FuiCs`
package depends on it and copies it into an application's publish folder; it
has no API of its own.
