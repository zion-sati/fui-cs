# Contributing to FUI-CS

> **Early stage.** FUI-CS is under active development and will change.

The [contributor quickstart](docs/v2/fui-cs/CONTRIBUTOR_QUICKSTART.md) covers
the prerequisites, the build, both unit test lanes, the browser tests, the
generated bindings and docs, and the repository layout.

In short, from the repository root:

```bash
dotnet build
dotnet test
```

## Getting in Touch

This is a solo project. If you're thinking about contributing, please open an
issue or start a discussion before writing code.
