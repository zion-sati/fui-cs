# FUI-CS SDK Docs Index (v2)

This is the navigation page for `v2/fui-cs`, the C# SDK for EffinDom retained
UI applications. FUI-CS compiles to WebAssembly with NetWasm and drives the
EffinDom UI runtime through the browser bridge. Its API is idiomatic C#:
properties with fluent members of the same name, multicast events, records for
colors and sizing, and `IDisposable` for anything holding native resources.
