# IndicatorPresenter

class in `FuiCs`

The indicator a [`IndicatorTemplate`](IndicatorTemplate.md) builds for a checkbox, radio button or switch: a root node that [`IndicatorPresenter.Apply`](IndicatorPresenter.md) restyles for each state.

## Properties

- `Root`: The indicator's root.

## Methods

- `Apply(Theme, IndicatorVisualState, LabeledControlColors)`: Restyles the indicator for `state`, with `colors` over the theme's.
