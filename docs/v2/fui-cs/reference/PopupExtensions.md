# PopupExtensions

class in `FuiCs`

Fluent configuration for [`Popup`](Popup.md) and its subclasses.

## Methods

- `AnchorGap(float)`: Sets [`Popup.AnchorGap`](Popup.md).
- `BackdropColor(Color)`: Sets [`Popup.BackdropColor`](Popup.md).
- `DismissOnBackdropClick(bool)`: Sets [`Popup.DismissOnBackdropClick`](Popup.md).
- `EdgePadding(float)`: Sets [`Popup.EdgePadding`](Popup.md).
- `OnClosed(Action)`: Adds a handler for the popup closing.
- `OnOpened(Action)`: Adds a handler for the popup opening.
- `PanelBackgroundBlur(float)`: Blurs the page behind the panel.
- `PanelBorder(Border)`: Draws a border around the panel.
- `PanelBorder(float, Color)`: Draws a solid border around the panel.
- `PanelColor(Color)`: Fills the panel.
- `PanelCornerRadius(float)`: Rounds the panel's corners.
- `PanelShadow(Color, float, float, float, float)`: Draws a shadow behind the panel.
- `Placement(PopupPlacement)`: Sets [`Popup.Placement`](Popup.md).
