# ScrollChangedEventArgs

class in `FuiCs`: `EventArgs`

A scroll view scrolling, or its content or viewport changing size.

## Properties

- `ExtentHeight`: The content's height.
- `ExtentWidth`: The content's width.
- `HorizontalOffset`: The horizontal offset.
- `VerticalOffset`: The vertical offset.
- `ViewportHeight`: The viewport's height.
- `ViewportWidth`: The viewport's width.
