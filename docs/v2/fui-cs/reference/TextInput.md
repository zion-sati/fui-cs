# TextInput

class in `FuiCs`: [`TextInputCore`](TextInputCore.md)

A single-line text field. Typing, pasting and the browser's editing keys edit [`TextInputCore.Text`](TextInputCore.md), Enter inserts nothing, and the arrows, Home and End move the caret without scrolling the page.
