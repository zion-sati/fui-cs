# ProgressBarExtensions

class in `FuiCs`

Fluent configuration for [`ProgressBar`](ProgressBar.md).

## Methods

- `FillColor(Color)`: Sets [`ProgressBar.FillColor`](ProgressBar.md).
- `FillLength()`: Sets [`ProgressBar.FillsLength`](ProgressBar.md): the bar fills its container along its orientation.
- `Length(float)`: Sets [`ProgressBar.Length`](ProgressBar.md).
- `Maximum(float)`: Sets [`ProgressBar.Maximum`](ProgressBar.md).
- `Minimum(float)`: Sets [`ProgressBar.Minimum`](ProgressBar.md).
- `Orientation(Orientation)`: Sets [`ProgressBar.Orientation`](ProgressBar.md).
- `Thickness(float)`: Sets [`ProgressBar.Thickness`](ProgressBar.md).
- `TrackColor(Color)`: Sets [`ProgressBar.TrackColor`](ProgressBar.md).
- `Value(float)`: Sets [`ProgressBar.Value`](ProgressBar.md).
