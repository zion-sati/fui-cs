# DropdownColors

record in `FuiCs`

Colors a dropdown uses instead of the theme's; unset colors follow the theme.

## Properties

- `Accent`: The selected option's label in the list, and a combo box's caret.
- `Background`: The field's fill.
- `Border`: The field's border.
- `Placeholder`: A combo box's placeholder text.
- `TextPrimary`: The selected value's text and the option labels.
