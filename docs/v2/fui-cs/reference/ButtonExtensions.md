# ButtonExtensions

class in `FuiCs`

Fluent configuration for [`Button`](Button.md).

## Methods

- `Colors(ButtonColors)`: Sets [`Button.Colors`](Button.md).
- `FontFamily(FontFamily)`: Sets the label's font family.
- `FontSize(float)`: Sets [`Button.FontSize`](Button.md).
- `FontStyle(FontStyle)`: Sets [`Button.FontStyle`](Button.md).
- `FontWeight(FontWeight)`: Sets [`Button.FontWeight`](Button.md).
- `HoverBackground(Color)`: Sets [`Button.HoverBackground`](Button.md).
- `Label(string)`: Sets [`Button.Label`](Button.md).
- `OnClick(Action<ClickEventArgs>)`: Adds a handler to [`Button.Click`](Button.md).
- `OnHoverChanged(Action<HoverChangedEventArgs>)`: Adds a handler to [`Button.HoverChanged`](Button.md).
- `PressedBackground(Color)`: Sets [`Button.PressedBackground`](Button.md).
- `Template(ButtonTemplate)`: Sets [`Button.Template`](Button.md).
- `TextColor(Color)`: Sets the label's color.
