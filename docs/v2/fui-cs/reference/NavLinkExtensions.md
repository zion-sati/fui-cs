# NavLinkExtensions

class in `FuiCs`

Fluent configuration for [`NavLink`](NavLink.md).

## Methods

- `Href(string)`: Sets [`NavLink.Href`](NavLink.md).
- `OnInteractionStateChanged(Action<NavLinkInteractionState>)`: Adds a handler to [`NavLink.InteractionStateChanged`](NavLink.md).
- `OnNavigate(Action<NavigateEventArgs>)`: Adds a handler to [`NavLink.Navigate`](NavLink.md).
- `OpenInNewTab(bool)`: Opens the link in a new tab.
