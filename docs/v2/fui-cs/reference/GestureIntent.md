# GestureIntent

enum in `FuiCs`

The touch gestures a node handles itself, so the host does not scroll or zoom the page for them.

## Values

- `None`: The node handles no gestures.
- `Pan`: The node handles one-finger pans.
- `Pinch`: The node handles two-finger pinches.
- `PanAndPinch`: The node handles pans and pinches.
