# ThemeFonts

record in `FuiCs`

The theme's font stacks and families; families default to regular/bold pairs of the stacks.

## Properties

- `BodyFamily`: The body text's family.
- `BodyStack`: The body text's stack.
- `HeadingFamily`: The headings' family.
- `HeadingStack`: The headings' stack.
- `MonoBoldStack`: The bold monospace stack.
- `MonoFamily`: The monospace family.
- `MonoStack`: The monospace stack.
- `SizeBody`: The body text's size in pixels.
- `SizeHeading`: The headings' size in pixels.
- `SizeMono`: The monospace text's size in pixels.

## Methods

- `Equals(ThemeFonts)`: Compares by reference, as every theme record does (see [`Theme`](Theme.md)).
- `GetHashCode()`: The reference's hash, matching the reference equality.
