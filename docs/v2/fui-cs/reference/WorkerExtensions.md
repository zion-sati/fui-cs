# WorkerExtensions

class in `FuiCs`

Fluent configuration for [`Worker`](Worker.md).

## Methods

- `OnCompleted(Action<WorkerCompletedEventArgs>)`: Adds a handler for the result.
- `OnError(Action<WorkerErrorEventArgs>)`: Adds a handler for errors.
- `OnProgress(Action<WorkerProgressEventArgs>)`: Adds a handler for progress messages.
