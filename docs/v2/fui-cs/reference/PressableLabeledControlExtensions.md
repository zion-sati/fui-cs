# PressableLabeledControlExtensions

class in `FuiCs`

Fluent configuration for checkboxes, radio buttons and switches.

## Methods

- `Colors(LabeledControlColors)`: Sets [`PressableLabeledControl.Colors`](PressableLabeledControl.md).
- `Label(string)`: Sets [`PressableLabeledControl.Label`](PressableLabeledControl.md).
- `OnClick(Action<ClickEventArgs>)`: Adds a handler to [`PressableLabeledControl.Click`](PressableLabeledControl.md).
- `Sizing(LabeledControlSizing)`: Sets [`PressableLabeledControl.Sizing`](PressableLabeledControl.md).
- `Template(IndicatorTemplate)`: Sets [`PressableLabeledControl.Template`](PressableLabeledControl.md).
