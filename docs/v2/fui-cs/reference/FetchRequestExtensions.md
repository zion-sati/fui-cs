# FetchRequestExtensions

class in `FuiCs`

Fluent configuration for [`FetchRequest`](FetchRequest.md).

## Methods

- `Body(byte[])`: Sets the request's body to raw bytes.
- `Body(string)`: Sets the request's body.
- `Header(string, string)`: Adds a header.
- `Method(string)`: Sets [`FetchRequest.Method`](FetchRequest.md).
