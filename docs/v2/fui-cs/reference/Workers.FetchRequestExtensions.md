# FetchRequestExtensions

class in `FuiCs.Workers`

Fluent configuration for [`FetchRequest`](Workers.FetchRequest.md).

## Methods

- `Body(byte[])`: Sets the body to `body`.
- `Body(string)`: Sets the body to `text` in UTF-8.
- `Header(string, string)`: Adds a header, as [`FetchRequest.AddHeader`](Workers.FetchRequest.md) does.
- `Method(string)`: Sets [`FetchRequest.Method`](Workers.FetchRequest.md).
