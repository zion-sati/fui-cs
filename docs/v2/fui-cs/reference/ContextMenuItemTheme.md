# ContextMenuItemTheme

record in `FuiCs`

How a context menu draws its items.

## Properties

- `Background`: An item's fill.
- `CornerRadius`: An item's corner radius.
- `FontFamily`: An item's font family.
- `FontSize`: An item's font size in pixels.
- `Height`: An item's height in pixels.
- `HoverBackground`: An item's fill under the pointer.
- `Padding`: An item's padding.
- `TextColor`: An item's text.

## Methods

- `Equals(ContextMenuItemTheme)`: Compares by reference, as every theme record does (see [`Theme`](Theme.md)).
- `GetHashCode()`: The reference's hash, matching the reference equality.
