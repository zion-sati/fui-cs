# DropdownSizing

record in `FuiCs`

Sizes for a dropdown's field, option rows and chevron; unset sizes follow the default templates.

## Properties

- `ChevronBoxSize`: The square the field keeps for the chevron.
- `ChevronIconSize`: The chevron icon's size inside its box.
- `FieldFontSize`: The field's font size; the default when null.
- `FieldHeight`: The field's height; grows to fit the font and chevron when null.
- `OptionFontSize`: The option rows' font size; the default when null.
- `OptionHeight`: The option rows' height; the default when null.
