# ToolTipTheme

record in `FuiCs`

How a tooltip looks.

## Properties

- `FontFamily`: The tooltip's font family.
- `FontSize`: The tooltip's font size in pixels.
- `MaxWidth`: The widest a tooltip grows before its text wraps.
- `Padding`: The tooltip's padding.
- `PanelBackground`: The tooltip's fill.
- `PanelBorderColor`: The tooltip's border.
- `PanelCornerRadius`: The tooltip's corner radius.
- `PanelShadowColor`: The tooltip's shadow color.
- `ShadowBlur`: The shadow's blur radius.
- `ShadowOffsetY`: The shadow's downward offset.
- `ShadowSpread`: The shadow's spread.
- `TextColor`: The tooltip's text.

## Methods

- `Equals(ToolTipTheme)`: Compares by reference, as every theme record does (see [`Theme`](Theme.md)).
- `GetHashCode()`: The reference's hash, matching the reference equality.
