# VirtualListExtensions

class in `FuiCs`

Fluent configuration for [`VirtualList`](VirtualList.md).

## Methods

- `OnBindItem(Action<FlexBox, int>)`: Sets [`VirtualList.BindItem`](VirtualList.md), which fills a row's container for an item index.
- `PersistScroll(bool)`: Saves the list's scroll offset with the page's state.
