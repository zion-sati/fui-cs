# DropdownChevronPresenter

class in `FuiCs`

The chevron a [`DropdownChevronTemplate`](DropdownChevronTemplate.md) builds; [`DropdownChevronPresenter.Apply`](DropdownChevronPresenter.md) restyles it for each state.

## Properties

- `Root`: The chevron's root.

## Methods

- `Apply(Theme, DropdownChevronVisualState)`: Restyles the chevron for `state`.
