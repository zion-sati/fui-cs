# SizableExtensions

class in `FuiCs`

Fluent sizing for every [`ISizable`](ISizable.md) node or layout.

## Methods

- `FillHeight()`: Makes the node fill the height its parent offers.
- `FillHeightPercent(float)`: Makes the node take `percent` of the remaining height.
- `FillSize()`: Makes the node fill both directions.
- `FillWidth()`: Makes the node fill the width its parent offers.
- `FillWidthPercent(float)`: Makes the node take `percent` of the remaining width.
- `Height(float, Unit)`: Sets a fixed height in `unit`.
- `Height(Length)`: Sets [`ISizable.Height`](ISizable.md).
- `MaxHeight(float, Unit)`: Sets the maximum height in `unit`.
- `MaxWidth(float, Unit)`: Sets the maximum width in `unit`.
- `MinHeight(float, Unit)`: Sets the minimum height in `unit`.
- `MinWidth(float, Unit)`: Sets the minimum width in `unit`.
- `Width(float, Unit)`: Sets a fixed width in `unit`.
- `Width(Length)`: Sets [`ISizable.Width`](ISizable.md).
