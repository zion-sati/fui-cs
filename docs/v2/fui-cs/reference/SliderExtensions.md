# SliderExtensions

class in `FuiCs`

Fluent configuration for [`Slider`](Slider.md).

## Methods

- `Colors(SliderColors)`: Sets [`Slider.Colors`](Slider.md).
- `Length(float)`: Sets [`Slider.Length`](Slider.md).
- `Maximum(float)`: Sets [`Slider.Maximum`](Slider.md).
- `Minimum(float)`: Sets [`Slider.Minimum`](Slider.md).
- `OnChanged(Action<SliderChangedEventArgs>)`: Adds a handler to [`Slider.Changed`](Slider.md).
- `Orientation(Orientation)`: Sets [`Slider.Orientation`](Slider.md).
- `Sizing(SliderSizing)`: Sets [`Slider.Sizing`](Slider.md).
- `Step(float)`: Sets [`Slider.Step`](Slider.md).
- `Template(SliderTemplate)`: Sets [`Slider.Template`](Slider.md).
- `Value(float)`: Sets [`Slider.Value`](Slider.md).
