# RadioGroupExtensions

class in `FuiCs`

Fluent configuration for [`RadioGroup`](RadioGroup.md).

## Methods

- `OnChanged(Action<RadioGroupChangedEventArgs>)`: Adds a handler to [`RadioGroup.Changed`](RadioGroup.md).
- `Option(string, string)`: Adds a radio for `value`, labelled `label` or the value.
- `Radio(ReadOnlySpan<RadioButton>)`: Adds radios to the group.
- `SelectedIndex(int)`: Sets [`RadioGroup.SelectedIndex`](RadioGroup.md).
