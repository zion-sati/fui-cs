# PointerButton

enum in `FuiCs`

The button that changed in a pointer event, numbered as the browser numbers them.

## Values

- `None`: No button changed, as in a move.
- `Primary`: The main button: the left mouse button, a touch or a pen contact.
- `Auxiliary`: The middle mouse button or wheel.
- `Secondary`: The right mouse button.
- `Back`: The browser-back button.
- `Forward`: The browser-forward button.
