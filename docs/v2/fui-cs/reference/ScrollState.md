# ScrollState

class in `FuiCs`

The scroll position and sizes of a [`ScrollView`](ScrollView.md) as signals, shared with the scroll bars and other views that follow it. The view keeps them current; a scroll bar moves the view through its own target binding.

## Properties

- `ContentHeight`: The content's height.
- `ContentWidth`: The content's width.
- `OffsetX`: The horizontal offset.
- `OffsetY`: The vertical offset.
- `ViewportHeight`: The viewport's height.
- `ViewportWidth`: The viewport's width.
