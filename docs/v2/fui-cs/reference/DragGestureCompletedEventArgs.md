# DragGestureCompletedEventArgs

class in `FuiCs`: `EventArgs`

A drag ending.

## Properties

- `Cancelled`: Whether the drag was cancelled rather than released.
- `Modifiers`: The modifier keys held.
- `TotalDeltaX`: The movement since the drag started.
- `TotalDeltaY`: The movement since the drag started.
- `X`: The pointer, relative to the node.
- `Y`: The pointer, relative to the node.
