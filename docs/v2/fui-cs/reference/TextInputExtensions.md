# TextInputExtensions

class in `FuiCs`

Fluent configuration for [`TextInputCore`](TextInputCore.md) controls.

## Methods

- `AcceptsTab(bool)`: Sets [`TextInputCore.AcceptsTab`](TextInputCore.md).
- `Caret(int)`: Puts the caret at a character position.
- `Colors(TextInputColors)`: Sets [`TextInputCore.Colors`](TextInputCore.md).
- `FontFamily(FontFamily)`: Sets [`TextInputCore.FontFamily`](TextInputCore.md).
- `FontSize(float?)`: Sets [`TextInputCore.FontSize`](TextInputCore.md).
- `HorizontalScrollBarVisibility(ScrollBarVisibility)`: Sets [`TextInputCore.HorizontalScrollBarVisibility`](TextInputCore.md).
- `HostAutofill(string)`: Sets [`TextInputCore.HostAutofill`](TextInputCore.md).
- `LineHeight(float?)`: Sets [`TextInputCore.LineHeight`](TextInputCore.md).
- `MaxChars(int?)`: Sets [`TextInputCore.MaxChars`](TextInputCore.md).
- `OnSelectionChanged(Action<SelectionChangedEventArgs>)`: Adds a handler to [`TextInputCore.SelectionChanged`](TextInputCore.md).
- `OnTextChanged(Action<TextChangedEventArgs>)`: Adds a handler to [`TextInputCore.TextChanged`](TextInputCore.md).
- `Password(bool)`: Sets [`TextInputCore.IsPassword`](TextInputCore.md).
- `Placeholder(string)`: Sets [`TextInputCore.Placeholder`](TextInputCore.md).
- `ReadOnly(bool)`: Sets [`TextInputCore.IsReadOnly`](TextInputCore.md).
- `Selection(int, int)`: Selects from `start` to `end` characters.
- `Template(TextInputTemplate)`: Sets [`TextInputCore.Template`](TextInputCore.md).
- `Text(string)`: Sets [`TextInputCore.Text`](TextInputCore.md).
- `VerticalScrollBarVisibility(ScrollBarVisibility)`: Sets [`TextInputCore.VerticalScrollBarVisibility`](TextInputCore.md).
- `Wrapping(bool)`: Sets [`TextInputCore.Wrapping`](TextInputCore.md).
