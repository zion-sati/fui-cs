# Span

class in `FuiCs`

A run of rich text. Unset properties inherit the [`RichText`](RichText.md)'s base style.

## Properties

- `Background`: The fill behind the span; null for none.
- `Color`: The span's text color; null uses the rich text's.
- `FontFamily`: The span's font family; null uses the rich text's.
- `FontSize`: The span's font size; null uses the rich text's.
- `FontStyle`: The span's font style; null uses the rich text's.
- `FontWeight`: The span's font weight; null uses the rich text's.
- `Strikethrough`: Strikes through the span.
- `Text`: The span's text.
- `Underline`: Underlines the span.
