# TextInputColors

record in `FuiCs`

Colors a text input or text area uses instead of the theme's; unset colors follow the theme.

## Properties

- `Accent`: An accent for templates to use; the default template does not.
- `Background`: The shell's fill.
- `Border`: The shell's border.
- `Caret`: The caret's color.
- `Placeholder`: The placeholder's color.
- `TextMuted`: The text while disabled.
- `TextPrimary`: The text's color.
