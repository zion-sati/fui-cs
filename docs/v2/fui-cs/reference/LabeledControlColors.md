# LabeledControlColors

record in `FuiCs`

Colors a checkbox, radio button or switch uses instead of the theme's; unset colors follow the theme.

## Properties

- `Accent`: The checked fill, used for every state instead of the theme's accent, hover and pressed colors.
- `Background`: The indicator's unchecked fill, and a switch's thumb.
- `Border`: The indicator's border.
- `TextMuted`: The label color while disabled.
- `TextPrimary`: The label's color.
