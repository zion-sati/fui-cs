# CheckboxExtensions

class in `FuiCs`

Fluent configuration for [`Checkbox`](Checkbox.md).

## Methods

- `IsChecked(bool?)`: Sets [`Checkbox.IsChecked`](Checkbox.md).
- `IsThreeState(bool)`: Sets [`Checkbox.IsThreeState`](Checkbox.md).
- `OnChanged(Action<CheckboxChangedEventArgs>)`: Adds a handler to [`Checkbox.Changed`](Checkbox.md).
