# FlexBoxExtensions

class in `FuiCs`

Fluent configuration for [`FlexBox`](FlexBox.md) and its subclasses.

## Methods

- `AlignItems(AlignItems)`: Sets [`FlexBox.AlignItems`](FlexBox.md).
- `AlignSelf(AlignSelf)`: Sets [`FlexBox.AlignSelf`](FlexBox.md).
- `Background(Color)`: Sets [`FlexBox.Background`](FlexBox.md).
- `BackgroundBlur(float)`: Blurs the page behind the box.
- `Blur(float)`: Blurs the box's own drawing.
- `Border(Border)`: Sets [`FlexBox.Border`](FlexBox.md).
- `Border(float, Color)`: Draws a solid border.
- `ClipToBounds(bool)`: Clips the children to the box's bounds.
- `CornerRadius(float, float, float, float)`: Rounds each corner by its own radius.
- `CornerRadius(float)`: Rounds every corner by `radius`.
- `DropShadow(Color, float, float, float, float)`: Draws a shadow behind the box.
- `FlexBasis(float)`: Sets the share of the main axis the box starts from before growing.
- `FlexDirection(FlexDirection)`: Sets [`FlexBox.FlexDirection`](FlexBox.md).
- `FlexWrap(FlexWrap)`: Sets [`FlexBox.FlexWrap`](FlexBox.md).
- `JustifyContent(JustifyContent)`: Sets [`FlexBox.JustifyContent`](FlexBox.md).
- `LinearGradient(float, float, float, float, GradientStop[])`: Fills the box with a linear gradient from the start point to the end point through `stops`.
- `Margin(float, float, float, float)`: Spaces each side.
- `Margin(float, float)`: Spaces the left and right, and the top and bottom.
- `Margin(float)`: Spaces every side equally.
- `Margin(Thickness)`: Sets [`FlexBox.Margin`](FlexBox.md).
- `Opacity(float)`: Sets the box's opacity, from 0 to 1.
- `Padding(float, float, float, float)`: Pads each side.
- `Padding(float, float)`: Pads the left and right, and the top and bottom.
- `Padding(float)`: Pads every side equally.
- `Padding(Thickness)`: Sets [`FlexBox.Padding`](FlexBox.md).
- `Position(float, float)`: Places an absolutely positioned box relative to its parent.
- `PositionAbsolute()`: Takes the box out of the flow, placed at Position.
- `PositionType(PositionType)`: Sets [`FlexBox.PositionType`](FlexBox.md).
- `Transitions(NodeTransitions)`: Sets which property changes animate.
