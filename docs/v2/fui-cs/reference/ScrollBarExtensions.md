# ScrollBarExtensions

class in `FuiCs`

Fluent styling for [`ScrollBar`](ScrollBar.md), as a [`ScrollBox`](ScrollBox.md)'s bars are restyled.

## Methods

- `MinThumbLength(float)`: Sets the shortest the thumb gets on long content.
- `ThumbColor(Color)`: Sets the thumb's color.
- `ThumbCornerRadius(float)`: Sets [`ScrollBar.ThumbCornerRadius`](ScrollBar.md).
- `ThumbThickness(float)`: Sets [`ScrollBar.ThumbThickness`](ScrollBar.md).
- `TrackColor(Color)`: Sets the track's color.
- `TrackCornerRadius(float)`: Sets [`ScrollBar.TrackCornerRadius`](ScrollBar.md).
- `TrackThickness(float)`: Sets [`ScrollBar.TrackThickness`](ScrollBar.md).
