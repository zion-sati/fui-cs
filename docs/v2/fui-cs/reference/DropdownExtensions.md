- `PopupPanelBackgroundBlur(float?)`: Sets [`Dropdown.PopupPanelBackgroundBlur`](Dropdown.md).
- `PopupPanelColor(Color?)`: Sets [`Dropdown.PopupPanelColor`](Dropdown.md).
- `PopupWidth(float?)`: Sets [`Dropdown.PopupWidth`](Dropdown.md).
- `SelectedIndex(int)`: Sets [`Dropdown.SelectedIndex`](Dropdown.md).
- `Sizing(DropdownSizing)`: Sets [`Dropdown.Sizing`](Dropdown.md).
