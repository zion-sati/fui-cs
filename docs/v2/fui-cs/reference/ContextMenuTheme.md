# ContextMenuTheme

record in `FuiCs`

How a context menu's panel looks.

## Properties

- `Item`: The items' style.
- `PanelBackground`: The panel's fill.
- `PanelBorderColor`: The panel's border.
- `PanelCornerRadius`: The panel's corner radius.
- `PanelShadowColor`: The panel's shadow color.
- `SeparatorColor`: The divider between groups.
- `ShadowBlur`: The shadow's blur radius.
- `ShadowOffsetY`: The shadow's downward offset.
- `ShadowSpread`: The shadow's spread.

## Methods

- `Equals(ContextMenuTheme)`: Compares by reference, as every theme record does (see [`Theme`](Theme.md)).
- `GetHashCode()`: The reference's hash, matching the reference equality.
