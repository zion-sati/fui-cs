# TabSelectionChangedEventArgs

class in `FuiCs`: `EventArgs`

A tab view's selection change: the tab that was selected and the one that is, or -1 and null for none.

## Properties

- `PreviousIndex`: The previously selected tab's index, or -1.
- `PreviousItem`: The previously selected tab, if any.
- `SelectedIndex`: The selected tab's index, or -1.
- `SelectedItem`: The selected tab, if any.
