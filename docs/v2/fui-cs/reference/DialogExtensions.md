# DialogExtensions

class in `FuiCs`

Fluent configuration for [`Dialog`](Dialog.md) and [`Form`](Form.md).

## Methods

- `BackdropColor(Color)`: Sets [`Dialog.BackdropColor`](Dialog.md).
- `Body(string)`: Sets [`Dialog.Body`](Dialog.md).
- `BodyContent(Node)`: Sets [`Dialog.BodyContent`](Dialog.md).
- `CancelButton(Button)`: Sets [`Form.CancelButton`](Form.md).
- `CardBorder(Border)`: Sets [`Dialog.CardBorder`](Dialog.md).
- `CardColor(Color)`: Sets [`Dialog.CardColor`](Dialog.md).
- `CardCornerRadius(float)`: Rounds the card's corners.
- `CardShadow(DropShadow)`: Sets [`Dialog.CardShadow`](Dialog.md).
- `DefaultButton(Button)`: Sets [`Form.DefaultButton`](Form.md).
- `OnAccepted(Action)`: Adds a handler to [`Dialog.Accepted`](Dialog.md).
- `OnCancelled(Action)`: Adds a handler to [`Dialog.Cancelled`](Dialog.md).
- `OnShown(Action)`: Adds a handler to [`Dialog.Shown`](Dialog.md).
- `Title(string)`: Sets [`Dialog.Title`](Dialog.md).
